API Reference Source Repository

Juicebox is a GDScript-based component library for Godot 4.x. It provides modular nodes for screen effects and procedural animations via composition.

Core Components

JuiceCamera2D / camera_2d.gd

Trauma-driven offset system. Samples 1D FastNoiseLite to generate coordinate displacement and rotation.

ImpactFrame / impact_frame.gd

Global time-scale manipulation. Overrides Engine.time_scale for specified durations to execute hitstop logic.

SquashStretch / squash_stretch.gd

Procedural scale interpolation. Updates parent scale vector using lerp toward Vector2.ONE.

GhostTrail / ghost_trail.gd

Dynamic sprite instantiation. Spawns Sprite2D clones and manages alpha-channel tweening.

PopLabelManager / pop_label.gd

Canvas-item motion control. Manages lifecycle and drift-velocity for floating combat text.

Specifications

  • 01 Pure GDScript; no C# or binary dependencies.
  • 02 Node-based composition (no inheritance required).
  • 03 Editor-integration via @tool scripts.
