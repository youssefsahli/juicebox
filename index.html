Juicebox is a GDScript-based component library for Godot 4.x. It provides modular nodes designed to implement screen effects and procedural animations via composition.

Core Components

JuiceCamera2D: Trauma-based offset system. Uses FastNoiseLite for 1D noise sampling to generate coordinate displacement and rotation.
ImpactFrame: Global time-scale manipulation. Overrides Engine.time_scale for a specific duration to execute hitstop logic.
SquashStretch: Procedural scale interpolation. Updates parent scale vector based on lerp functions toward a neutral Vector2.ONE.
GhostTrail: Dynamic sprite instantiation. Generates Sprite2D clones at defined intervals and manages alpha-channel tweening.
PopLabelManager: Canvas-item motion control. Handles the instantiation and lifecycle management of combat text labels.

Specifications

  • • No C# or GDExtension dependencies.
  • • Node-based composition; no inheritance required.
  • • Signal-compatible public APIs.
  • • Editor-integration via @tool scripts.
