Composition

All features are standalone nodes. Add them as children to any Player, Enemy, or UI element without refactoring existing code.

Zero Setup

Nodes work with industry-standard default settings immediately. Drop a JuiceCamera2D in your scene and it's ready to shake.

Signal Driven

Trigger effects via standard Godot signals. Connect area_entered to your juice node and watch it come alive.

The "Big 5" Modules

JuiceCamera2D

Trauma-based shake using FastNoiseLite for organic, decaying camera movement.

ImpactFrame

High-impact hitstop (freeze frames) and screen flashes to emphasize critical actions.

Squash & Stretch

Procedural deformation for sprites to add weight to jumping, landing, and movement.

GhostTrail

Spawns trailing after-images for high-speed characters or dash effects.

PopLabelManager

A high-performance system for spawning floating combat text and numbers.
